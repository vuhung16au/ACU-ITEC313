# Installing Maven (mvn)

Here is a brief guide on how to install Apache Maven on different operating systems using the command line.

## macOS (using Homebrew)

If you have [Homebrew](https://brew.sh/) installed, you can install Maven with a single command:

```bash
brew install maven
```

## Ubuntu / Debian

You can install Maven using the `apt` package manager:

```bash
sudo apt update
sudo apt install maven
```

## Windows

The easiest way to install Maven on Windows via the command line is by using a package manager like [Chocolatey](https://chocolatey.org/) or [Scoop](https://scoop.sh/).

**Using Chocolatey:**
```powershell
choco install maven
```

**Using Scoop:**
```powershell
scoop install maven
```

*(Alternatively, for Windows you can manually download the zip file, extract it, and add the `bin` directory to your system's `PATH` variable, but package managers provide the simplest command-line installation).*

## Verifying the Installation

After installing, verify that Maven is correctly installed and in your system's PATH by running:

```bash
mvn -version
```

## Configuring Maven for JavaFX (Java 25, JavaFX 25)

To configure your `pom.xml` for a JavaFX project targeting Java 25 and JavaFX 25, you need to set the compiler properties and plugin release version to `25`, and include the JavaFX 25 dependencies.

Here is a sample `pom.xml` configuration:

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
  xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/maven-v4_0_0.xsd">
    <modelVersion>4.0.0</modelVersion>
    <groupId>org.openjfx</groupId>
    <artifactId>sample</artifactId>
    <version>1.0.0</version>
    
    <properties>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
        <maven.compiler.source>25</maven.compiler.source>
        <maven.compiler.target>25</maven.compiler.target>
    </properties>
    
    <dependencies>
        <dependency>
            <groupId>org.openjfx</groupId>
            <artifactId>javafx-controls</artifactId>
            <version>25</version>
        </dependency>
    </dependencies>
    
    <build>
        <plugins>
            <plugin>
                <groupId>org.apache.maven.plugins</groupId>
                <artifactId>maven-compiler-plugin</artifactId>
                <version>3.14.0</version>
                <configuration>
                    <release>25</release>
                </configuration>
            </plugin>
            <plugin>
                <groupId>org.openjfx</groupId>
                <artifactId>javafx-maven-plugin</artifactId>
                <version>0.0.8</version>
                <executions>
                    <execution>
                        <!-- Default configuration for running -->
                        <!-- Usage: mvn clean javafx:run -->
                        <id>default-cli</id>
                        <configuration>
                            <mainClass>org.openjfx.App</mainClass>
                        </configuration>
                    </execution>
                </executions>
            </plugin>
        </plugins>
    </build>
</project>
```

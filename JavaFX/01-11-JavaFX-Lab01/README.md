# Overview 

This project demonstrates how to turn a Hello World JavaFX application into a complex application using by adding new features and functionalities using AI Coding agents. 

# How to add new features and functionalities using AI Coding agents

# Step 0: 

Make sure you have a working JavaFX project with a basic Hello World application using maven (`mvn`)

Check point: You should be able to run the Hello World application using the command line:

```bash
mvn clean javafx:run
```

# Step 1:

Prepare a requirement description for the new feature or functionality you want to add to your JavaFX application. 

A sample product requirement defintion document is under `<root>/PRD.md` file. You can use this as a template to create your own requirement description, or use it as-is.

# Step 2:

Copy-paste the requirement description into the AI Coding agent's input prompt.

# Verify the result:

- Run `mvn clean javafx:run` to verify that the new feature or functionality has been successfully added to your JavaFX application.
- Test the new app and fix any issues if necessary.

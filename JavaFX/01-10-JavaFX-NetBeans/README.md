# Overview 

How to build a Hello World application using JavaFX in NetBeans IDE.

Link: https://netbeans.apache.org/front/main/download/

## Step 0: Install JDK 17+ or later

Recommended: JDK 25 latest TLS version. As of 11 Aug, 2026, the latest version is JDK 25

## Step 1: Download NetBeans IDE 

Download the latest version of [NetBeans](https://netbeans.apache.org/front/main/download/) IDE from the official website. 

File name: `netbeans-xx-bin.zip`, e.g. `netbeans-31-bin.zip` (or the latest version available).

As of 11 Aug, 2026, the latest version is NetBeans 31.

## Install NetBeans IDE GUI

(YouTube) [ITEC621 - Week02 - Hello JavaFX - NetBeans 31(Aug 2026)](https://youtu.be/ODPynkl-9Rk)

## How to Use

Build with command line:

```bash
mvn clean javafx:run
```
